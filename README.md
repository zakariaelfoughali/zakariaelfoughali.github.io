# مدونة Zakariaelfoughali

موقع شخصي ثابت (HTML + CSS + JavaScript) بدون أي أطر عمل أو خادم. المقالات داخل الموقع نفسه في ملف `script.js`.

## الملفات

- `index.html` هيكل الصفحة.
- `styles.css` التصميم.
- `script.js` المقالات والتنقل والبحث ونموذج التواصل.

## تشغيل الموقع محليًا

افتح `index.html` في المتصفح مباشرة. لا يلزم تثبيت أي شيء.

## النشر على GitHub Pages

1. أنشئ حسابًا على github.com ثم مستودعًا جديدًا (مثال: `zakariaelfoughali.github.io` لتحصل على رابط بدون مسار فرعي).
2. ارفع الملفات الثلاثة `index.html` و`styles.css` و`script.js` و`README.md` إلى جذر المستودع (Add file ← Upload files ← Commit changes).
3. من تبويب Settings ثم Pages اختر Deploy from a branch، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. انتظر دقيقة تقريبًا وافتح الرابط الظاهر في أعلى صفحة Pages.

## النشر على GoogieHost

1. سجّل الدخول إلى لوحة التحكم وافتح File Manager.
2. ادخل المجلد `htdocs` (أو `public_html` حسب الخطة) واحذف الملف الافتراضي إن وُجد.
3. ارفع `index.html` و`styles.css` و`script.js` إلى المجلد نفسه.
4. افتح نطاقك في المتصفح للتأكد.

## ما الذي تغيّره

- **البريد الإلكتروني:** غيّر الثابت `EMAIL` في أعلى `script.js`، وغيّر `hello@example.com` في `index.html` (رابط البريد في قسم تواصل).
- **الروابط الاجتماعية:** في `index.html` ابحث عن `class="social"` وعدّل قيم `href` (GitHub وX وInstagram). احذف أي عنصر `<li>` لا تحتاجه.
- **الاسم والعنوان والوصف:** عدّل الوسوم `title` و`meta description` و`og:*` في أعلى `index.html`، وغيّر `og:url` إلى رابط موقعك الحقيقي.
- **الألوان:** المتغيرات في أعلى `styles.css` داخل `:root`.

## إضافة مقال جديد

افتح `script.js` وأضف كائنًا جديدًا إلى المصفوفة `POSTS`:

```js
{
  slug: 'my-new-post',          // يظهر في الرابط: #/post/my-new-post (حروف إنجليزية وشرطات)
  title: 'عنوان المقال',
  excerpt: 'ملخص قصير يظهر في البطاقة.',
  date: '2026-11-05',           // بصيغة YYYY-MM-DD
  tags: ['وسم1', 'وسم2'],
  readTime: 3,                  // بالدقائق
  content: [
    'فقرة عادية.',
    '## عنوان فرعي (يبدأ بعلامتي # ومسافة)',
    'فقرة أخرى.'
  ]
}
```

يُرتَّب المقال تلقائيًا حسب التاريخ، وتظهر الوسوم الجديدة في الفلترة تلقائيًا.
